什么是 ICO 格式？为什么要转换为 ICO？

ICO（Icon File Format）是 Windows 操作系统中用于存储图标（icon）的专用文件格式。与普通图片格式相比，ICO 格式具有独特的优势，使其成为系统图标、网站 favicon 等场景的首选格式。

ICO 转换常见问题 (FAQ)

Q1：ICO 格式有什么用？
A：ICO 是 Windows 系统的图标文件格式，主要用于：1) 网站 favicon 图标（浏览器标签页显示）；2) 桌面快捷方式图标；3) 应用程序图标；4) 文件夹图标等。它可以将多个尺寸的图标打包在一个文件中，适应不同的显示环境。
Q2：哪些尺寸的 ICO 最常用？
A：Windows 系统最常用的 ICO 尺寸是 16×16（小型显示，如标题栏）、32×32（标准大小，如文件夹）、48×48（大图标，如桌面）。建议至少选择 16×16、32×32、48×48 三个尺寸的组合，以获得最佳兼容性。网站 favicon 推荐 32×32 或 64×64。
Q3：支持透明背景吗？
A：是的，转换后的 ICO 文件完美支持 Alpha 透明通道，可以保留原图的透明背景效果。这对于需要透明背景的图标（如软件 logo、emoji 图标）非常重要。
Q4：我的图片会被上传到服务器吗？
A：完全不会！本工具是一款"纯前端本地图片转换器"。所有的图片编解码工作都在您电脑或手机的浏览器中进行，不需要上传到服务器，因此不仅不消耗图片上传流量，转换速度还取决于您的设备性能，断网状态下也能正常使用。
Q5：支持批量转换吗？
A：支持！您可以同时上传多达 20 个图片文件，一键批量转换为 ICO 格式，并打包下载所有结果。批量处理功能可以大大提升工作效率，特别适合需要为多个项目创建图标的开发者。
Q6：转换后的图标模糊怎么办？
A：如果原图分辨率较低，放大后可能会出现模糊。建议使用尺寸大于 256×256 的高清原图（最好是 512×512 或更高分辨率），以获得最佳的 ICO 转换效果。对于图标来说，原始图片越大，缩小后的效果越好。
Q7：支持哪些输入格式？
A：本工具支持 PNG、JPG（JPEG）、GIF、WebP 等主流图片格式的输入。其中 PNG 和 WebP 格式支持透明背景，JPG 格式不支持透明背景（背景会变为白色）。建议优先使用 PNG 格式以获得最佳效果。
Q8：为什么选择 PNG 转 ICO？
A：PNG 格式支持 Alpha 透明通道，可以完美保留图标中的透明区域，是转换 ICO 图标的最佳选择。相比之下，JPG 格式不支持透明，转换后背景会变为白色，影响图标效果。
Q9：PNG转ICO需要注意什么？
A：1) 建议使用正方形图片，非正方形图片会被自动裁剪；2) 原图分辨率越高，转换后的 ICO 效果越好；3) 如果原图有透明背景，确保图片边缘平滑；4) 选择合适的尺寸组合，一般建议至少包含 16×16、32×32、48×48。
Q10：如何为网站添加 favicon.ico？
A：1) 使用本工具将 Logo 图片转换为 ICO 格式；2) 将生成的 favicon.ico 文件上传到网站根目录；3) 在 HTML 的 head 中添加代码：<link rel="icon" href="assets/favicon.ico" type="image/x-icon">；4) 刷新浏览器缓存即可看到效果。
Q11：圆角率设置有什么作用？
A：圆角率决定 ICO 图标的圆角程度。0% 为直角图标，25% 为轻微圆角，50% 为半圆角（接近圆形），100% 为完全圆角。现代设计趋势中，网站图标常用 0%-20%，应用图标常用 25%-50%，社交类图标常用 50%-100%。
Q12：转换后的 ICO 图标在 Mac 上能用吗？
A：可以的！虽然 ICO 是 Windows 原生格式，但 macOS 也支持 ICO 格式的图标。不过 macOS 更常用 ICNS 格式，如果需要专门用于 Mac 的图标，建议额外转换为 ICNS 格式。
